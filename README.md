## Featured Projects

### 🤖 Spring AI Document Classifier
> Java 21 · Spring AI · AWS Bedrock · OpenAI API · Kafka · DynamoDB

Enterprise document ingestion pipeline that auto-classifies and routes incoming documents using LLM inference. Built on the same architecture as my production work at IBM/NYC DSS.

- RAG-powered classification with vector similarity search
- Kafka event bus for async processing + SQS dead-letter queues
- REST + GraphQL APIs with Spring Boot 3.5

---

### 🔍 RAG Knowledge Assistant
> Spring Boot · LangChain4j · PGVector · PostgreSQL · React.js

Conversational query assistant over a custom enterprise knowledge base. Embeds documents into a vector store and retrieves contextually relevant chunks using semantic search before LLM generation.

- Implements full RAG pipeline: chunking → embedding → retrieval → generation
- Spring Security + JWT authentication
- React.js chat UI with streaming responses

---

### ⚡ Kafka Microservices Pipeline
> Java 17 · Spring Boot · Apache Kafka · AWS SQS/SNS · Docker · Kubernetes

Event-driven order processing system demonstrating real-world microservices decomposition — the same pattern used to reduce system downtime 40% at IBM.

- Producer/consumer services with retry + DLQ patterns
- Kubernetes deployment with Helm charts and auto-scaling
- Prometheus + Grafana observability stack
